# Employee Management System - Frontend

This project contains the frontend of the Employee Management System sample web application, made with Vite and React.

The backend for this web application can be found here:
-[ Employee Management System - Backend](https://github.com/JesseHerrera04/ems-backend)

This project was made to further develop my skills in React and Vite/Node development.
It works in conjunction with the backend, a Java Spring Boot application, to simulate a real world web application.
